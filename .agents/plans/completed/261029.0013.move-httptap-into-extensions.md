## Overview

Delete the `httptap` package. Its four production files move into `extensions` with the
`http_` prefix, their tests move beside them in the same package, and the documentation
stops naming `httptap`. This is a breaking change under the pre-stable 1.0.x policy and
is documented in the existing `[Unreleased]` BREAKING CHANGES table.

No behaviour changes except the listed nil-argument panic strings.

## Owner decisions

- Every `doc.go` in the module is deleted; no new `doc.go` is created. Affected files:
  root `doc.go` (added in b804d63), `extensions/doc.go`, `adapters/doc.go`,
  `httptap/doc.go` (goes with the package), `internal/integrations/axiom/doc.go`.
  Root `doc.go` is removed, not updated.
- Content that users need is kept in godoc, the rest is dropped:
  - the Axiom delivery contract from `extensions/doc.go` (async, bounded, best-effort,
    possible duplicates, `Close`/`Shutdown` before exit, `log.Fatal`/`os.Exit` lose the
    queue, `xaat-` token kind with `xapt-` rejected, defaults) moves into the godoc of
    `AxiomHandler` and `NewAxiomHandler`;
  - the always-on redaction statement moves into the godoc of `NewPayloadHandler`,
    `NewPayloadHandlerWithOptions`, and the redaction options (`WithRedactHeaders`,
    `WithRedactQueryParams`).
- Package comments: if `godoclint` (enabled in `.golangci.yml`) requires one, a short
  1-3 line package comment goes above the package clause of the primary file
  (`extensions/file.go`, `adapters/levels.go`, `internal/integrations/axiom/handler.go`).
  Otherwise no package comment is added.

## Conventions for every task

- Gate before each commit: `make verify` and `CGO_ENABLED=0 go test ./...`, both green.
  Never `--no-verify`. Commit explicit paths only.
- Commit subjects are conventional (`refactor(extensions): ...`, `docs: ...`); bodies end
  with `#37`; body lines wrapped at 72.
- R16 per production file: exported vars and consts, then the primary exported type,
  its constructor, then its methods, then other exported types and functions, then
  unexported declarations. Mirror `extensions/http.go` (the access handler moved in the
  previous restructure).
- R17: each test file mirrors its production file. Shared test helpers sit at the bottom
  of one test file, not in a `testutil_test.go`.
- R47: explicit `t.Run` subtests in new code; moved tests keep their names and
  `t.Parallel()` and `nolint` lines.
- R50: call arguments on one line or one per line. R12: no import aliases.
- R1: interface assertions stay in test assertion blocks; mocks/fakes carry `var _ Iface`.
