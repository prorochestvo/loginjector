# Decide whether R50 applies to testify assertion calls

- raised: 2026-11-04 — standards audit P3 of plan 261029.0012 (R50), deferred by the owner
- decision: open

About 1,600 test lines have the form `require.Equal(t, want, f(x))`, a call as an argument on one line. A strict reading of R50 requires one argument per line for them; the project currently treats testify one-liners as exempt, and R47's own example uses a one-line `t.Errorf` with several arguments. Decide whether the exemption stands (and record it) or the tests are reformatted.
