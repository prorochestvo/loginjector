# Compile the httptap doc example

- raised: 2026-10-22 — deferred by plan 261022.0011 (project hygiene, Decision 10)
- decision: open

The usage example in the `httptap/doc.go` package comment is plain comment text, so the compiler never checks it; it had drifted to assigning two results from `loginjector.NewLogger` and `httptap.NewPayloadHandlerWithOptions`, which return one each. Plan 261022.0011 fixed the text only. Convert the example to a compiled `Example` function in an `example_*_test.go` file (as `httptap/example_access_test.go` does for the access handler) and reduce the package comment to a pointer, so the example cannot drift again.
