# Decide whether the HTTP middleware options get a feature prefix

- raised: 2026-11-04 — standards audit P3 of plan 261029.0013 (R13), deferred by the owner
- decision: open

After the httptap move, the payload and recover options (`WithMaxRequestBody`, `WithMaxResponseBody`, `WithoutBodies`, `WithRedactHeaders`, `WithRedactQueryParams`, `WithSummaryWriter`, `WithFallbackResponse`, `WithFallbackContentType`, `WithPublicMessage`) share the `extensions` package with the file, print and Axiom options. The Axiom options carry an `Axiom` infix for that reason; the HTTP ones do not, and `WithoutBodies` or `WithPublicMessage` do not say they belong to HTTP middleware. They shipped unprefixed in v1.0.10, so renaming them is now a breaking change. Decide whether to rename them in a later release, and to what.
