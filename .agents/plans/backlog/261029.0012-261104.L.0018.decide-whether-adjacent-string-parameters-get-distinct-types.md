# Decide whether adjacent string parameters get distinct types

- raised: 2026-11-04 — standards audit P3 of plan 261029.0012 (R3/R24), deferred by the owner
- decision: open

`extensions.TelegramHandler(botToken, chatID, fileName string, ...)`, `extensions.RotatingFileHandler(folder, prefix string, ...)` and `extensions.NewFileLogger(folder, prefix string, ...)` take adjacent parameters of the same string type that a caller can swap without a compile error. Distinct named types (as `AxiomToken` and `AxiomDataset` do) would catch that, at the cost of a breaking signature change. Decide whether and when.
