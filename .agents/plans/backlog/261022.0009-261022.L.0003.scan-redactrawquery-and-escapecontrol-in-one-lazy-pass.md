# Scan redactRawQuery and escapeControl in one lazy pass

- raised: 2026-10-22 — standards audit of plan 261022.0009 (httptap hardening), deferred as P3
- groomed: 2026-11-15 16:49Z
- decision: open

`redactRawQuery` (extensions/http_redact.go) and `EscapeControl` (internal/httpx/escape.go) each scan the input twice — a match/needs-escape pre-scan and a rewrite pass with duplicated segment logic. Fold each into one pass that starts a `strings.Builder` only at the first change, keeping zero allocations when nothing matches; add `BenchmarkRedactRawQuery` and `BenchmarkEscapeControl` with `-benchmem`.

Rewritten 2026-11-15 (grooming): the httptap package was removed by plans 261029.0012 and 261029.0013; the functions now live at the paths above, and `escapeControl` is exported as `EscapeControl`. Both still pre-scan and then rewrite.
