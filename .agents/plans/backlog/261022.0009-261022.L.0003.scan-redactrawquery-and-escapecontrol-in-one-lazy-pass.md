# Scan redactRawQuery and escapeControl in one lazy pass

- raised: 2026-10-22 — standards audit of plan 261022.0009 (httptap hardening), deferred as P3
- decision: open

`redactRawQuery` (httptap/redact.go) and `escapeControl` (httptap/escape.go) each scan the input twice — a match/needs-escape pre-scan and a rewrite pass with duplicated segment logic. Fold each into one pass that starts a `strings.Builder` only at the first change, keeping zero allocations when nothing matches; add `BenchmarkRedactRawQuery` and `BenchmarkEscapeControl` with `-benchmem`.
