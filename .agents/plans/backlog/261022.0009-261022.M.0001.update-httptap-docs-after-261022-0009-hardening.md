# Update httptap docs after 261022.0009 hardening

**Status:** open (high priority)  
**Affects:** `AGENTS.md`, `README.md`, `doc.go`  
**Blocks:** release hygiene

## Issue

Plan 261022.0009 updated httptap redaction and response-writer semantics. The following docs are now stale:

- `AGENTS.md:74` and `README.md:75` list the old four-header default set (`Authorization`, `Cookie`,
  `Set-Cookie`, `Proxy-Authorization`) and omit `X-Api-Key`, `X-Auth-Token`, and query-parameter
  redaction. The security contract section must be updated to list all six default headers and
  mention the seven default query-parameter names.

- `README.md:75-76` advises keeping `NewRecoverHandler` off SSE/streaming routes because it buffers
  the body. This is now stale: Task 7 (261022.0009) implemented `Flush` commit semantics, so streaming
  handlers that call `Flush` are supported. The advice should be updated or removed.

- `doc.go`'s example assigns two results from `NewPayloadHandlerWithOptions`, which returns one
  `http.HandlerFunc`. The syntax must be corrected.

## Tasks

1. Update `AGENTS.md:74` security-contract section: add `X-Api-Key`, `X-Auth-Token`; add query-parameter
   default set (`access_token`, `refresh_token`, `id_token`, `client_secret`, `api_key`, `apikey`, `password`).

2. Update `README.md:75-76`: replace streaming/SSE advice with new semantics ("streaming handlers that
   call `Flush` are supported; a panic after `Flush` aborts with `http.ErrAbortHandler`").

3. Fix `doc.go` example: remove the erroneous second assignment.
