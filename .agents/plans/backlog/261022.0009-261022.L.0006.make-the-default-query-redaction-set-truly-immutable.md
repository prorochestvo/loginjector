# Make the default query redaction set truly immutable

- raised: 2026-10-22 — standards audit of plan 261022.0009 (httptap hardening), deferred as Worth a look
- decision: open

`defaultRedactQueryParams` in httptap/redact.go is a package-level map documented as immutable, but nothing prevents mutation. Make it a slice copied into each config, or an unexported function returning a fresh set, and fix the godoc.
