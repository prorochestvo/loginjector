# Encode Axiom events without encoding/json on the caller goroutine

- raised: 2026-10-28 — deferred by plan 261021.0006 (architecture review, P2)
- decision: open

`axiom.Handler` encodes each event on the caller goroutine. Inside a `Logger` that runs under the per-sink mutex, so every logging goroutine waits on it. Measured before the round-1 fixes (Apple M1): a 100 B message took 1.6 µs, 16 allocs and 2.2 KB; `appendEvent` held 68% of allocated bytes. Round 1 presized the buffer and disabled HTML escaping. The remaining cost is `encoding/json` itself.

Proposal: a small stdlib `appendJSONString(dst, []byte)` that escapes `"`, `\`, control characters, and invalid UTF-8 (as U+FFFD). It writes the timestamp with `time.AppendFormat` and targets 1 alloc per event. It needs a fuzz test against `encoding/json` for byte-equivalent decoding before it can replace the encoder.
