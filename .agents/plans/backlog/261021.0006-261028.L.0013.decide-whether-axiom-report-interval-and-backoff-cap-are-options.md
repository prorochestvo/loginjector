# Decide whether the Axiom report interval and backoff cap are options

- raised: 2026-10-28 — deferred by plan 261021.0006 (standards audit, R27, unverified)
- decision: open

The 30 s error-report rate limit, the 10 s retry backoff cap and the 512 KiB message limit are fixed constants in `axiom`. The audit asked whether they are protocol facts or policy a library user should be able to tune. The message limit follows Axiom's field limit. The other two are policy. No user has asked for them. Add an option only when a concrete need appears.
