# Build-tag the umask call in rotating_newopts_test.go

- raised: 2026-10-22 — implementation of plan 261022.0010 (file handler retention), pre-existing on main
- decision: open

`GOOS=windows go vet ./...` fails because `rotating_newopts_test.go` calls `syscall.Umask`, which does not exist on Windows, in a file without a build constraint. Production code builds for Windows (`GOOS=windows go build ./...` passes). Move the umask-dependent test into a `//go:build unix` test file (as `filelogger_unix_test.go` does) and add `GOOS=windows go vet ./...` to the verification target so the regression is caught.
