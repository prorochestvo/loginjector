# Task Breakdown

## Overview

Ship logs produced by `loginjector.Logger` to Axiom (https://axiom.co/docs) as structured
events. Two pieces are required. First, handlers currently receive only message bytes, so
a remote structured sink cannot record the severity; the root package gains an optional,
additive `LevelWriter` interface through which `Logger.WriteLog` passes the level to
sinks that ask for it. Second, a new opt-in subpackage `axiom/` provides a batching,
asynchronous, stdlib-only handler that POSTs NDJSON to the Axiom ingest API without
blocking the logging call path. Existing handlers and output stay byte-identical. Target
release: v1.1.0 (new `Added` surface, no breaking change).

## Assumptions

- Axiom ingest API (verified 2026-10-21 against https://axiom.co/docs/send-data/ingest,
  /reference/edge-deployments, /reference/limits):
  - `POST https://<domain>/v1/ingest/<dataset>`, header `Authorization: Bearer <token>`,
    `Content-Type: application/x-ndjson`.
  - Edge domains: `us-east-1.aws.edge.axiom.co`, `eu-central-1.aws.edge.axiom.co`; the
    dataset's region must match the domain.
  - `_time` is the timestamp field (RFC3339 accepted); missing `_time` falls back to
    ingest time.
  - Limits: 10,000 events per batch; 1 MB per field; 200-byte field names; 256 fields per
    dataset on personal plans (1,024 soft on Cloud); rate limiting is applied to
    high-frequency, high-volume senders.
- Unverified, confirmed by the Task 6 smoke test:
  - request `Content-Encoding: gzip` is accepted on the edge endpoint;
  - a successful response is HTTP 200 with a JSON body
    `{"ingested":N,"failed":M,"failures":[{"timestamp":...,"error":"..."}],...}`;
  - a 4 MiB uncompressed request body is within the endpoint's request size limit.
  If any of these is wrong, the affected default changes (gzip off, smaller batch bytes) or
  the response parser is adjusted; the plan records the result.
- Tokens: the edge ingest endpoint takes an Axiom API token (`xaat-` prefix) scoped to
  ingest on the dataset. Personal tokens (`xapt-`) additionally require an
  `X-Axiom-Org-Id` header and are not supported in this iteration. Provisioning the token
  is an owner action outside this plan.
- Consumers log free-form text (`Printf`, `log.New(logger.WriterAs(...))`, `StdLog`).
  Each message becomes the `message` string field; parsing structured payloads out of the
  message is out of scope (see Trade-offs).
- No owner-feedback file is open in `.agents/plans/`; nothing blocks this plan.
- Go toolchain floor stays at `go 1.22.2` (`go.mod`); `math/rand/v2` is available.

## Decisions

Each decision lists its reason and how to reverse it.

1. **Subpackage `axiom/`, not a root handler.** Mirrors `httptap/`: network-specific code
   stays opt-in. It also allows the subpackage to import `levels` for the default level
   names; the root cannot (`levels` imports the root — an import cycle). Reversal: move
   the files into the root package and replace the `levels.Name` default with a numeric
   formatter.
2. **Optional `LevelWriter` interface in the root package** instead of per-level hooks or
   parsing the level from text. Hooks-per-level multiply registrations and break
   `WithMinLevel` semantics; text parsing is fragile. Pattern precedent: `LeveledHandler`.
   Reversal: the interface is additive; removing it later is a breaking change, so it is
   reviewed as public API now.
3. **Asynchronous, bounded, drop-on-full.** `Logger.WriteLog` waits for every sink, so a
   synchronous HTTP call per line would put network latency on every log call and invite
   rate limiting. The queue is bounded both by event count and by bytes; on overflow the
   event is dropped and counted; logging never blocks the application because the log
   backend is down. Reversal: a `WithBlockOnFull()` option can be added later without
   changing defaults.
4. **Stdlib only** (`net/http`, `encoding/json`, `compress/gzip`); no `axiom-go`. Keeps the
   dependency contract in `AGENTS.md`. Reversal: none needed; the wire format is small.
5. **Default domain `us-east-1.aws.edge.axiom.co`**, overridable with `WithDomain`. Axiom's
   own default region. Reversal: change the constant (behavioural change, CHANGELOG note).
6. **Concrete return type `*axiom.Handler`** (accept interfaces, return structs), because
   the caller needs `Flush`/`Shutdown`/`Close`/`Stats`, which `io.Writer` does not expose.
7. **Writes after shutdown are counted, not returned as errors.** `Printf`/`Print` print
   every `WriteLog` error to stderr via `println`; returning `ErrClosed` from `Write` would
   spam stderr for every line logged during shutdown. After `Close`, `Write` returns
   `len(p), nil` and increments `Dropped`. `ErrClosed` is returned only by `Flush` and
   `Shutdown` called after shutdown. Reversal: return `ErrClosed` from `Write` (behavioural
   change).
8. **Every error-handler call is rate-limited and panic-guarded**, including a
   user-supplied handler: at most one call per 30s (fixed, unexported), carrying a count of
   suppressed errors, wrapped in `recover()`. This bounds the loop when a consumer routes
   errors back into the same `Logger` and keeps a panicking handler from killing the
   worker. Default handler writes one line to `os.Stderr`. Reversal: expose the interval as
   an option if a consumer needs it.
9. **Shutdown API mirrors `http.Server`**: `Shutdown(ctx)` with a caller deadline, `Close()`
   = `Shutdown` with a fixed 5s bound. Replaces the earlier `WithShutdownTimeout` option
   (one method instead of a permanent option). Reversal: add the option later; additive.
10. **Delivery is at-least-once.** Retrying a POST after a network error can duplicate a
    batch already accepted by Axiom. Documented in the README; no idempotency key exists in
    the ingest API to prevent it.

### Task 1: `LevelWriter` dispatch in the root package
- Description: Add to `logger.go`:

  ```go
  // LevelWriter is an optional interface a handler or hook may implement to receive
  // the severity of each message. When a sink implements it, Logger.WriteLog calls
  // WriteLevel instead of Write. Implementations must not retain p after returning.
  type LevelWriter interface {
      io.Writer
      WriteLevel(level LogLevel, p []byte) (n int, err error)
  }
  ```

  Dispatch rules:
  - `*writer` (the `ensureThreadSafe` wrapper) gains `WriteLevel`: it takes the same mutex
    as `Write`, and calls `original.WriteLevel` when `original` implements `LevelWriter`,
    otherwise `h(p)`. The mutex guarantee for sinks is unchanged. A `*writer` built by
    `WriterAs` has `original == nil` and falls back to `h(p)`.
  - `leveledWriter` (`WithMinLevel`) gains `WriteLevel`, forwarding to `inner.WriteLevel`
    when `inner` is a `LevelWriter`, else `inner.Write`. So
    `WithMinLevel(levels.Warning, axiomHandler)` still receives levels, including when
    nested (`WithMinLevel(X, WithMinLevel(Y, lw))`).
  - In `WriteLog`, both the inline fast path and the concurrent fan-out call one helper
    `writeSink(w io.Writer, level LogLevel, p []byte)` that prefers `WriteLevel`. Hooks go
    through the same helper.
  - `WriterAs`, `StdLog`, `Write`, `Printf`, `Print` already route through `WriteLog` and
    need no change; verify by test. (`JoinAs` no longer exists since v1.0.9.)
  - Godoc on `LevelWriter` states: the no-retain contract; the dispatch rule; that package
    handlers wrapping a user writer internally through a closure (e.g.
    `TimestampedHandler(ax)`) do not forward the level; and that an existing user type
    that already has a `WriteLevel(LogLevel, []byte)` method now receives calls through it.
- Acceptance Criteria:
  - A test `LevelWriter` registered via `NewLogger`, via `WithMinLevel` (single and nested),
    and via `Hook` receives the exact level passed to `WriteLog`, `Printf`,
    `WriterAs(level)`, and `StdLog(level, ...)`.
  - Plain `io.Writer` handlers receive byte-identical input as before: existing tests pass
    unchanged, plus an explicit test that `WithMinLevel(X, TimestampedPrintHandler(...))`
    output is unchanged.
  - Return values of `WriteLog` are unchanged (0 when only hooks below the minimum fired).
  - `TestLogger_WriteLevelForRaceCondition`: many goroutines log at mixed levels into a
    non-thread-safe `LevelWriter`; `-race` clean; the count per level matches.
- Pitfalls & edge cases: `ensureThreadSafe` returns an existing `*writer` unchanged — make
  sure double wrapping cannot bypass the mutex.
  WriteLevel must take the same mutex as `(*writer).Write` (`w.shared` when set, else `w.m`): factor that selection out of `Write` into one helper once WriteLevel becomes its second caller, and extend writeSink rather than add a second dispatch helper.
- Complexity: Medium

### Task 2: `axiom` package — configuration and event encoding
- Description: Create `axiom/doc.go`, `axiom/handler.go`, `axiom/options.go`.

  Public surface:

  ```go
  func NewHandler(token, dataset string, opts ...Option) (*Handler, error)

  func (h *Handler) Write(p []byte) (int, error)
  func (h *Handler) WriteLevel(level loginjector.LogLevel, p []byte) (int, error)
  func (h *Handler) Flush(ctx context.Context) error
  func (h *Handler) Shutdown(ctx context.Context) error
  func (h *Handler) Close() error                      // Shutdown with a 5s bound
  func (h *Handler) Stats() Stats                      // {Sent, Dropped, Failed uint64}, in events

  func WithDomain(domain string) Option                 // default "us-east-1.aws.edge.axiom.co"
  func WithFields(fields map[string]any) Option         // static fields on every event
  func WithLevelName(fn func(loginjector.LogLevel) string) Option // default levels.Name
  func WithBatchSize(n int) Option                      // default 1000, max 10000
  func WithMaxBatchBytes(n int) Option                  // default 4 MiB, min 1 MiB
  func WithFlushInterval(d time.Duration) Option        // default 1s
  func WithQueueSize(n int) Option                      // default 10000 events
  func WithMaxQueueBytes(n int) Option                  // default 32 MiB
  func WithHTTPClient(c *http.Client) Option            // default: Timeout 10s
  func WithMaxRetries(n int) Option                     // default 3
  func WithCompression(enabled bool) Option             // default true (gzip)
  func WithErrorHandler(fn func(error)) Option          // default: stderr; always rate-limited

  var ErrClosed = errors.New("axiom: handler closed") // from Flush/Shutdown after shutdown
  ```

  Event shape, one JSON object per line:

  ```json
  {"_time":"2026-10-21T10:00:00.123456789Z","level":"warning","level_num":3,
   "message":"disk almost full","service":"beacon","env":"prod"}
  ```

  - `_time`: UTC, RFC3339Nano, captured in `Write`/`WriteLevel` (not at send time).
  - `message`: the bytes with trailing `\r\n`/`\n` trimmed, converted to a string; invalid
    UTF-8 is left to `encoding/json`, which replaces it with U+FFFD.
  - Messages longer than 512 KiB are truncated at a UTF-8 boundary and carry
    `"message_truncated": true` (under Axiom's 1 MB field limit with margin).
  - `level`/`level_num` are present only for `WriteLevel`; a plain `Write` (handler used
    directly as an `io.Writer`) emits neither. Godoc of `WithLevelName` notes that the
    default `levels.Name` returns `"unknown"` for levels outside 1..6, and `level_num`
    keeps such events filterable.
  - `WithFields` is encoded once at construction into a JSON fragment (the caller's map is
    not retained, so later mutation cannot race with the worker). Keys `_time`, `level`,
    `level_num`, `message`, `message_truncated`, and any key starting with `_` are
    rejected; values that fail `json.Marshal` are rejected.
  - `Handler` has no `String`/`GoString`; the token is held in an unexported field only.
  - `User-Agent: loginjector-axiom` (no version: the library has no version source).
- Acceptance Criteria:
  - `NewHandler` validates: non-empty token and dataset; a token with the `xapt-` prefix is
    rejected with an error explaining that an API token (`xaat-`) is required; dataset
    contains no `/`; domain is a bare host (no scheme, no path); numeric options are
    positive and within the stated limits (`WithMaxBatchBytes` >= 1 MiB so a single
    maximum-size event always fits a batch).
  - The ingest URL is built with `url.PathEscape(dataset)`.
  - Unit tests for encoding cover: trailing-newline trim, truncation at a multi-byte
    boundary, level present/absent, static fields merged, reserved-key rejection,
    non-encodable field rejection, caller map mutated after `NewHandler` has no effect.
- Pitfalls & edge cases: the `writer` contract forbids retaining `p` — copy into the event
  before enqueueing; tests decode JSON rather than compare raw strings (map order).
- Complexity: Medium

### Task 3: `axiom` package — queue, batching worker, delivery
- Description: Implement the background pipeline in `axiom/handler.go` and
  `axiom/send.go`.
  - **Admission.** `Write`/`WriteLevel` hold `mu.RLock()` across the closed check, the
    byte-budget check, and the non-blocking channel send. `Shutdown` takes `mu.Lock()` to
    set `closed`, so no event can enter the channel after the worker's final drain begins.
    The channel is never closed. On a full channel, an exhausted byte budget (atomic
    in-flight byte counter, decremented when an event leaves a batch), or a closed handler:
    increment `Dropped`, return `len(p), nil`.
  - **Worker.** One goroutine started by `NewHandler` and owned by the `Handler`. It holds a
    worker context created at construction. It accumulates events and sends when the batch
    reaches `WithBatchSize` events or `WithMaxBatchBytes` encoded bytes, or when the flush
    ticker fires with a non-empty batch. The ticker is stopped on exit.
  - **Encoding.** NDJSON into a reused `bytes.Buffer`, gzip when enabled
    (`Content-Encoding: gzip`), headers `Authorization: Bearer <token>`,
    `Content-Type: application/x-ndjson`, `User-Agent: loginjector-axiom`.
  - **Request.** `http.NewRequestWithContext(workerCtx, ...)`; response body read through
    `io.LimitReader` (64 KiB), then drained and closed for connection reuse.
  - **Response handling.** HTTP 200: decode `{"ingested","failed","failures"}`; add
    `ingested` to `Sent` and `failed` to `Failed`; report the first failure reason through
    the error handler. A 200 whose body cannot be decoded counts the whole batch as `Sent`
    and reports a decode error. 429, 5xx, and network errors: retry. Other 4xx: count the
    batch as `Failed`, report, no retry.
  - **Retry.** Up to `WithMaxRetries` attempts with exponential backoff (base 250ms, cap
    10s, full jitter). `Retry-After` is parsed as delay-seconds or as an HTTP date via
    `http.ParseTime`, capped at 30s, falling back to the computed backoff when unparseable.
    Every wait is a `select` on a timer and the worker context. Backoff sleep and clock go
    through an unexported seam so tests do not wait in real time.
  - **Errors.** Messages include status code and at most 1 KiB of the response body; they
    never include the token or request headers. All reports go through the rate-limited,
    panic-guarded error dispatcher (Decision 8). When `Dropped` grew since the last report,
    the dispatcher emits `axiom: dropped N events`.
  - **Flush(ctx).** Snapshots the number of events queued at call time; the worker sends
    those plus the pending batch and acknowledges. Returns `ctx.Err()` on deadline,
    `ErrClosed` after shutdown (the call `select`s on the worker-done channel, so it never
    hangs). Events written after the call are not waited for.
  - **Shutdown(ctx) / Close().** Idempotent (`sync.Once`; later calls return the first
    result). Sets `closed` under the write lock, signals the worker to drain the queue and
    send the final batch. On `ctx` deadline it cancels the worker context, which aborts the
    in-flight request and any backoff wait; events not delivered are added to `Failed`.
    It waits for the worker goroutine to exit before returning. If the `Handler` built its
    own `http.Client`, it calls `CloseIdleConnections()`; a client passed via
    `WithHTTPClient` is never touched. `Close()` = `Shutdown` with a 5s deadline.
  - **Invariant.** After `Shutdown` returns, every `Write`/`WriteLevel` call is counted
    exactly once in `Sent + Dropped + Failed` (events, not batches). Duplicates from
    at-least-once retries are not detectable client-side and are not counted.
- Acceptance Criteria (tests against `httptest.Server`, all under `-race`):
  - Batch-by-count, batch-by-bytes, and batch-by-interval each produce the expected number
    of requests and events; events decode from gzip NDJSON with correct fields.
  - 200 with `failed > 0` in the body → `Failed` incremented by `failed`, error reported.
  - 429 with `Retry-After: 1` (seconds) and with an HTTP-date value → retried, delay taken
    from the header via the test clock seam; 5xx beyond max retries → batch counted in
    `Failed`, one error report; 400 → no retry.
  - Event-count queue full and byte budget exhausted → `Dropped` increments, `Write` does
    not block (bounded test duration); the periodic drop report reaches the error handler.
  - Error handler: rate-limited (two failures inside the interval → one call with a
    suppressed count); a panicking handler does not stop delivery of later batches.
  - `Flush`: delivers events written before the call; returns `ctx.Err()` against a
    hanging server; returns `ErrClosed` after `Close`.
  - `Close` delivers everything queued before it; `Write` after `Close` returns
    `len(p), nil` and increments `Dropped`; `Close` twice returns the same result;
    `Shutdown` with a short deadline against a hanging server and against a pending
    `Retry-After` backoff returns within the deadline, counts undelivered events as
    `Failed`, and the worker has exited.
  - Caller mutates the slice passed to `Write` after the call → sent event unchanged.
  - Captured error strings never contain the token.
  - `TestHandler_WriteForRaceCondition`: 50 goroutines × 1,000 writes through a
    `loginjector.Logger`, `Close` at the end; `Sent + Dropped + Failed` equals total writes.
  - No goroutine leaks after `Close` (goroutine count before/after with a settle loop; no
    `t.Parallel()` in that test; no new dependency such as `goleak`).
- Pitfalls & edge cases: time-based tests use the clock seam or short intervals with
  generous deadlines — no fixed `time.Sleep` assertions; the byte budget counter must be
  decremented on every exit path (sent, failed, dropped at shutdown).
- Complexity: Hard

## Risks

- **Event loss on crash or missing `Close`.** In-memory queue only; up to one flush
  interval plus the queue is lost on `kill -9` or a panic exit. Mitigation: documented;
  `Fatal`/`Fatalf` panic, so consumers should `defer ax.Close()` in `main` and recover at
  the top level. Disk spooling is out of scope.
- **Memory.** Bounded by `WithMaxQueueBytes` (32 MiB default) plus one batch
  (`WithMaxBatchBytes`, 4 MiB) and its gzip buffer.
- **Axiom field explosion.** Static fields are fixed at construction and the message is a
  single string, so the field count per dataset stays constant (about 5 + static fields).
- **Rate limiting under bursts.** Batching keeps request frequency near one per flush
  interval under normal load; retries use jitter.
- **Duplicates.** At-least-once delivery after network-error retries (Decision 10).
- **Unverified API facts.** gzip, response body shape, request size — covered by Task 6.
- **Public API is permanent.** `LevelWriter` and the `axiom` surface are reviewed as API
  before merge (never break API silently).

## Trade-offs

- **Drop-on-full vs. backpressure**: availability of the application over completeness
  of logs.
- **Text `message` vs. structured parsing**: no `WithJSONMessages` option that would merge
  JSON-object messages into event fields. Useful only if consumers log JSON, which the
  blessed pattern (`StdLog`/`log.New`) does not. Can be added later as an additive option.
- **Own client vs. `axiom-go`**: no SDK features (query, OTel), but zero new dependencies
  and full control of batching semantics.
- **No personal-token support**: avoids an `X-Axiom-Org-Id` option; additive later.
- **`LevelWriter` for `TelegramHandler`** (level in the caption) is possible but not done
  here to keep its output byte-identical.
